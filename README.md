# 리뷰 운영 대시보드

`2026_플랫폼별 리뷰 답글 관리` Google Sheets를 읽어 운영 현황과 리뷰 통계를 보여주는 바닐라 HTML/CSS/JavaScript 대시보드입니다.

## 연결 방식

- Google Sheets가 유일한 원본입니다.
- 대시보드는 Google Visualization JSONP 응답을 읽기 전용으로 사용합니다.
- 페이지를 열거나 새로고침 버튼을 누르면 최신 시트 내용을 다시 읽습니다.
- 열린 화면은 1분마다 자동 갱신됩니다.
- 상단에 최근 성공한 갱신 날짜·시간(KST)을 표시하고 새로고침 후 10초 동안 중복 요청을 막습니다.
- 상단에서 한국어·영어·중국어(간체)·일본어와 라이트·다크 모드를 선택할 수 있습니다. 선택은 현재 브라우저에 저장됩니다.
- 언어 변경은 인터페이스에만 적용됩니다. 원본 리뷰, 답글과 시트 기록은 번역하거나 변경하지 않습니다.
- AI/담당자 답글 수는 작성 주체가 명시된 완료 기록만 집계합니다. 불명확한 작성 주체는 별도로 표시합니다.
- 저평점 기준은 공개 5점 척도에서 3.5점 이하입니다. 평균 평점은 문의를 제외하고 평점이 기록된 리뷰만 집계합니다.
- 동일한 플랫폼·리뷰 ID는 가장 최근 상태 한 건으로 집계합니다.
- 고객 작성자명은 표시하지 않으며, 리뷰·답글 안의 이메일·전화번호는 브라우저에서 가립니다.
