# 리뷰 운영 대시보드

`2026_플랫폼별 리뷰 답글 관리` Google Sheets를 읽어 운영 현황과 리뷰 통계를 보여주는 바닐라 HTML/CSS/JavaScript 대시보드입니다.

## 연결 방식

- Google Sheets가 유일한 원본입니다.
- 대시보드는 Google Visualization JSONP 응답을 읽기 전용으로 사용합니다.
- 페이지를 열거나 새로고침 버튼을 누르면 최신 시트 내용을 다시 읽습니다.
- 열린 화면은 1분마다 자동 갱신됩니다.
- 상단에 최근 성공한 갱신 날짜·시간(KST)을 표시하고 새로고침 후 10초 동안 중복 요청을 막습니다.
- 상단에서 한국어·영어·중국어(간체)·일본어와 라이트·다크 모드를 선택할 수 있습니다. 선택은 현재 브라우저에 저장됩니다.
- 언어 변경은 인터페이스에만 적용됩니다. 원본 리뷰, 답글과 시트 기록은 번역하거나 변경하지 않습니다.
- AI/담당자 답글 수는 작성 주체가 명시된 완료 기록만 집계합니다. 불명확한 작성 주체는 별도로 표시합니다.
- 저평점 기준은 공개 5점 척도에서 3.5점 이하입니다. 평균 평점은 문의를 제외하고 평점이 기록된 리뷰만 집계합니다.
- 동일한 플랫폼·리뷰 ID는 가장 최근 상태 한 건으로 집계합니다.
- 고객 작성자명은 표시하지 않으며, 리뷰·답글 안의 이메일·전화번호는 브라우저에서 가립니다.
- 보류 사유는 원본의 업무 사유를 기준으로 담당자가 이해할 수 있는 문장으로 표시합니다. 내부 도구 호출·로그인 복구·실행 로그는 화면에 노출하지 않습니다. 원본 기록은 보존합니다.
- 플랫폼별 관리 화면과 각 기록의 원본 시트 행을 새 탭으로 엽니다. 플랫폼 링크는 관리 목록이며 개별 리뷰로 바로 이동하는 주소는 아닙니다.
- 시트 행 번호는 헤더·빈 행을 포함한 실제 원본 위치를 유지합니다.

# 공동 처리완료 (Apps Script)

기존 GitHub Pages URL은 유지합니다. `completion.js`의 endpoint는 담당자 승인 후 배포한 Apps Script 웹앱 `/exec` URL입니다. 비밀번호와 이용자 Google 로그인은 사용하지 않습니다.

- 소유자 프로젝트: https://script.google.com/home/projects/15b5uEE7nkpI6rZVwuMd36Epv4jemn-3CoeWSOie-oIaU1LQJVioWMIX8/edit
- 기록 탭: `대시보드 담당자 처리기록` (gid `1682712709`), A:H. 원본 여섯 개 탭은 읽기만 합니다.
- D열 TRUE = 담당자 처리완료, FALSE = 되돌리기. 같은 A열 기록키의 마지막 이벤트가 현재 상태입니다. 실제 답글을 게시했다는 뜻은 아닙니다.
- POST는 허용된 원본 탭의 기존 기록만 검증한 뒤 완료 상태를 추가 기록합니다. 원본 본문, 답글, 보류 사유를 수정하지 않습니다.
- 요청 ID 중복 처리 방지, 버전 충돌 검사, 행 이동 시 내용 지문 재확인, 변경 이력 보존을 적용합니다. 원문 내용이 바뀌면 기존 완료표시는 자동 승계하지 않습니다.
- 로그인 없으므로 변경자를 실명으로 식별하지 못하며, 링크를 아는 누구나 완료/되돌리기를 할 수 있습니다. 민감자료 접근통제 용도로 사용하지 마세요.
- 대시보드는 POST의 불투명 응답을 성공으로 간주하지 않습니다. GET으로 해당 요청 ID의 저장 영수증을 확인한 후 표시를 갱신합니다. GET은 읽기 전용입니다.
- 다른 화면은 새로고침/기존 1분 갱신 시 반영됩니다. 필터 `담당자 처리완료`에서 완료된 항목을 찾아 체크를 해제할 수 있습니다.
- 통계는 원본 답글 상태 기준이고, 업무 대기 목록/KPI에서는 담당자 완료 항목을 제외합니다.
- 워커가 중복 작업하지 않게 하려면 이 기록 탭의 마지막 상태도 읽도록 별도 연결이 필요합니다. 기존 워커 프롬프트·실행환경은 이 코드 변경으로 자동 변경되지 않습니다.

검증: `node tests/dashboard.test.cjs`, `node tests/completion.test.cjs`. 합성 데이터로 검증하며 실제 고객 리뷰를 임의 완료 처리하지 않습니다.
